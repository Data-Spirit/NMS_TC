## 🎮 What is this?

> **No Man's Sky lets you customize names** (bases, ships, freighters, multi-tools, storage containers, star systems, and more) using an in-game text-tag system for **colors and icons** that Hello Games has never officially documented.
> 
> _The information exists, but has historically been scattered across screenshots, player trial-and-error, forums, and community guides._
> 
> **NMS // TEXT CODES** brings this information together into a **single structured and interactive reference guide** — designed to work both as a reference and as a practical tool while you play.

## 🛠️ How to Use

**Download** → _open the HTML file in your browser_ → _pick your language (or let it be detected)_ → _search or browse the tables_ → _click to copy_ → _paste in-game_.

**No installation is required**, and the guide is designed to work **fully offline** once downloaded.

_You can also browse the hosted version directly from your browser through **🌐Online Version**._

## ✨ Why this guide stands out

* 🌍 **Multilingual, in a single file :** Several languages are built in, with a **language selector**. The guide picks your browser's language automatically and remembers your choice.
* 📦 **A single, fully self-contained HTML file :** no installation, no critical external dependencies. Open it in your browser, **offline, anywhere**.
* 🎨 **59 color tags** documented with **exact HEX code, transparency and category**, plus **4 clickable sort modes** *(name, color, HEX, luminosity)* and instant search.
* 🖼️ **145 real in-game icons**, individually extracted and cleaned by hand *(not generic placeholders)*, grouped into **12 categories**, with **duplicate / non-functional / unconfirmed status badges :**  all 145 icons are embedded directly in the file, with **no external images needed**.
* ⚡ **A live simulator :** type your tags and see the result rendered instantly, before pasting it in-game — including the well-known **icon-tinting trick**, and **instant error detection** for misspelled or wrongly cased tags.
* 📝 **Examples :** includes **10 real, in-game usage examples** to get you started, each one **copyable in a click**.
* ⧉ **One-click copy :** on every row of the color and icon tables, on every example, and in the simulator.
* 🎭 **A "meta" visual identity :** the interface's own accent colors are borrowed directly from the **real in-game tags** it documents.
* 💾 **Built to last :** no ephemeral spreadsheet links, no forum posts scattered across years of replies: just **one file** you can download and consult offline, whenever you need it.
* 🔍 **Full transparency** about what's confirmed, uncertain, or non-functional — nothing is presented with more certainty than it deserves.

<div align="center">
   <h1>Release + PATCH NOTES</h1> 
   <em>— v2.0 — One file, every language —</em>
</div>

<br>

**v2.0 is the first release since v1.1.** It rolls up the work of the intermediate development versions **1.2** and **1.3** (never published as releases) and delivers the biggest change of the project so far: the three separate guides — `NMS_txt_code_FR.html`, `NMS_txt_code_EN.html` and `NMS_txt_code_ES.html` — are replaced by **a single standalone `NMS_txt_code.html`** that contains every language and a built-in language selector.

## 🔎 Highlights

- 🌍 **One file, every language.** All the languages live in the same HTML file. Switch instantly from the selector; the guide detects your browser language on the first visit and remembers your choice afterwards.
- 📉 **Three files become one, and the total weight drops by about 62%** (≈ 938 KB for the three v1.1 files → ≈ 358 KB). Adding a language now costs only **≈ 13–14 KB** instead of a whole new guide.
- ⚡ **A smarter simulator.** A one-click copy button, and real-time error detection for unknown, misspelled or wrongly cased tags, with the fix suggested.
- ⧉ **Copy any real-world example** to your clipboard in one click.
- 🔒 **Safe by design.** Every translated text goes through a strict tag whitelist before reaching the page.
- 📚 **Documented and tested.** Detailed READMEs for every language, documented translation workflows, and automated checks for every language.

## ⚠️ Breaking changes & migration

- **One file replaces three.** `NMS_txt_code_FR.html`, `NMS_txt_code_EN.html` and `NMS_txt_code_ES.html` are no longer published: download **`NMS_txt_code.html`** instead and pick your language inside the guide. The previous per-language files are archived in the repository (`docs/_legacy/`) and are no longer maintained.
- **New online address.** The hosted guide is now a single page: https://data-spirit.github.io/NMS_TC/LANG/NMS_txt_code.html — update any bookmark that points to the old per-language pages.
- **No data change.** The tag syntax and the data are the same as in v1.1: the same 59 color tags, 145 icon tags, 12 categories, 21 duplicate textures, 16 non-functional and 12 unconfirmed entries. Nothing you already use in-game changes.
- **Language preference.** The language you choose is remembered locally in your browser (`localStorage`, key `nmstc-lang`). Nothing is ever sent anywhere.

## ✨ Added

### 🌍 Multilingual system *(new in 2.0)*
- **Language selector** at the top right of the page. Each language is listed under its own name, preceded by its flag.
- **Multilingual by design**: every language has the same **116 translatable texts**, with French as the **source language**. All the language editions that existed as separate files in v1.1 are now merged into the single file.
- **Smart language choice on load:** the previously saved choice first; otherwise the browser's language (an exact match like `es`, or the base language of a regional one like `es-MX`); otherwise French.
- **Instant switching, no reload:** texts, tables, category filter, simulator messages and examples are all re-rendered, and the page title and `<html lang>` follow the language.
- **Graceful fallback:** a text missing in a language is shown in French rather than as a blank or an error. Missing keys are also tracked internally to make translation gaps easy to spot.
- **One block per language.** Each language is an independent JSON block (`<script type="application/json" id="i18n-xx">`) placed at the end of the file, starting with a `_meta` header: native name, flag, language code, translation version, source version and the translation parameters used (tone, variant, fidelity). A block that fails to load is ignored without affecting the other languages.
- **Adding a language means adding one block**, with no change to the code. Each block weighs about 13–14 KB.

### ⚡ Live simulator *(versions 1.2 and 1.3)*
- **Copy button** next to the input field: larger than the table buttons, and aligned on the height of the field. It copies the code exactly as typed (the raw text, not the preview) and does nothing if the field is empty, so an empty clipboard is never written. A ✓ confirms the copy.
- **Error detection** for tag names:
  - an unknown color or icon (a typo such as `REDD` instead of `RED`) is underlined in red with a wavy line, directly in the preview;
  - a small box below the preview names each faulty tag and, when one exists, shows the correct name;
  - case is checked, as in the game: `red`, `fuel` or `<img>` in lowercase are flagged with the fix to apply (`RED`, `FUEL`, `IMG`);
  - the error line only appears when there is an error, so the layout never jumps.
- **Clear button** (×) inside the field to start over in one click, a discreet **placeholder** hint in the empty field, and a preview frame that keeps its height whether it is empty or not.

### 📋 Real-world examples *(versions 1.2 and 1.3)*
- A **copy button on each of the 10 container examples**, so you can drop a ready-made name straight into your game.

### 📚 Documentation & tooling
- **A design README for every language** (see *Available Languages* above) — documenting the design of the guide, including the multilingual system and how to add a language.
- **Reusable translation prompts** in [`docs/prompts/`](https://github.com/Data-Spirit/NMS_TC/tree/main/docs/prompts): one to translate a language block of the guide, one to translate the README.
- **Automated check scripts** in [`docs/scripts/`](https://github.com/Data-Spirit/NMS_TC/tree/main/docs/scripts) (see *Validation performed* below).

## 🔄 Changed

- **Single standalone file.** All languages live in `NMS_txt_code.html`. The French text, previously written directly in the page, is now the `i18n-fr` block, the **source language** from which the other languages are translated.
- **Texts come from translation keys.** 62 elements of the page are filled from their key (`data-i18n`), and 7 more get translated attributes such as placeholders and `aria-label`s (`data-i18n-attr`). The tables, the simulator and the examples are generated from the same keys.
- **Language-neutral data.** Category names and status badges (duplicate, non-functional, to verify) are no longer stored as text in the data: the tables hold neutral identifiers (e.g. `resources`, `goods_tech`) that are looked up in the active language.
- **Two translation helpers**, so a text always goes through the right path: `T(key, params)` returns sanitized HTML, `TA(key, params)` returns plain text (attributes, `textContent`). Dynamic values use `{param}` placeholders. Both are cached per language and per key, so each text is processed only once.
- **Code layout.** The language blocks sit after the main script, so the page initialization now waits for the end of loading. `ICON_DATA` stays at the end of the script, before the language blocks.
- **README restructured** to describe the multilingual guide, with the new "Adding or updating a language" chapter.

## 🔒 Security

- **Translations are treated as untrusted input.** Every translated text is parsed in an inert `<template>` (nothing runs during parsing) and cleaned with a whitelist: only `A`, `B`, `BR`, `CODE`, `EM`, `I`, `SPAN` and `STRONG` are kept, and every other tag is turned into plain text.
- **Attributes are whitelisted too.** `href` must start with `http(s)://` or `#`; `class` is limited to letters, digits, `-`, `_`; `target` can only be `_blank`; `rel` letters only. Event handlers (`onclick…`) and `javascript:` links can never reach the page — a community translation cannot inject code.
- **Storage failures are tolerated.** Reading or writing the saved language is wrapped in `try/catch`, so the guide still works when the browser blocks `localStorage`.
- **Unchanged from v1.1:** the simulator escapes the typed text before recognizing tags, so anything that is not a genuine NMS tag stays inert text.

## ♿ Accessibility

- The language selector is a **native `<select>`** with an accessible label.
- The page's **`lang` attribute follows the chosen language**, helping screen readers pick the right voice.
- The new simulator buttons (copy, clear) carry an **`aria-label` and a tooltip**, in every language, as do the search fields and the category filter.

## ⚡ Performance

- **62% lighter overall** than the three v1.1 files, and a single download.
- **Translations are processed once**: sanitized HTML and plain-text versions are cached per language and key.
- Switching language re-renders the page without reloading it.

## 🧪 Validation performed

The checks below were run on the final `NMS_txt_code.html`, in every language:

- **Keys and safety** (`trans_script_1_check_keys.py`, strict mode): **29 checks passed, 0 failed**. Same keys in every language, matching `{params}` and code snippets, only whitelisted tags, no event handler or `javascript:` link.
- **Behavior** (`trans_script_2_test_behavior.js`, jsdom): **34 checks passed for each language.** Copy and clear buttons, tag-error messages, examples, tabs and the rendering of valid inputs.
- **Robustness** (`trans_script_3_test_robustness.js`): all passed. A malicious translation (`<img onerror>`, `javascript:` link, `onclick`, `iframe`, `svg`) is neutralized; an unreadable language block is ignored; a partial language falls back to French and its missing keys are reported; the browser language is detected and the chosen language remembered; the page still works when `localStorage` is blocked.
- **Render equivalence** (`trans_script_4_test_render.js`): across a series of interactions (simulator, searches, sorts, filter, tabs, language switch and back), the languages already present render **identically** before and after a new language block is added. Adding a language did not alter the existing ones.
- **HTML validation** (`html-validate`, `recommended` and `standard` presets): **0 errors**, with two rules deliberately disabled (`empty-heading` and `text-content`), since headings and buttons are filled with their translated text at load time.

> These checks validate the logic and the generated structure in jsdom, **not the behavior in real browsers** nor the visual appearance.

## 📌 Known limitations

- **Right-to-left languages** (Arabic, Hebrew…) are **not supported yet**: the layout would be incorrect.
- The language selector's **flags are emoji**: some systems display two letters instead of a flag.
- Same documented limits as before: 16 listed icon tags are **non-functional** (kept in reserve in case Hello Games assigns them a texture), 12 icon textures remain **unconfirmed**, the exact color of `TRANS_ANM` is unconfirmed, and the **icon-tinting trick** is an observed in-game behavior, not a documented guarantee.
