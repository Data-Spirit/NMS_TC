# Roadmap

Where **NMS // TEXT CODES** is heading. This is a living list, not a promise: priorities can change, and anything done moves to the [changelog](CHANGELOG.md).

---

## 🔧 In progress

- **Nexus Mods page** — publish the guide on Nexus Mods once the project is mature enough; the Nexus badge in the README will then point to the real page.

## 📌 Planned

- **More languages** — German next. Long-term goal: every language officially supported by No Man's Sky. Each new language follows `docs/prompts/prompt_add_language_NMS_TC.md`.
- **Italian: game terms** — compare a few Italian terms with the game's own Italian wording: portal glyphs (« Simboli del portale », maybe « Glifi » in game), multi-tools (« multiutensili »), companions (« Compagni ») and base building (« Costruzione base »).
- **Italian: native proofreading** — have the Italian guide and README proofread by a native speaker.
- **Message shown without JavaScript** — with 4 languages it takes 6 lines on a phone (375 px); reformat it (for example one language per line) before reaching 5 or 6 languages, ideally together with German.
- **Controller icons (`*_W`)** — the controller button textures (Steam, Xbox, PlayStation, Switch…) have been found in the game files; test in game whether these 16 tags display them before updating the guide.

## 💡 Ideas (not scheduled)

- **Right-to-left languages** (Arabic, Hebrew…): the layout would need `dir="rtl"` support.
- **Non-Latin alphabets**: fonts with a wider character coverage, to avoid fallback fonts.
- **Flag fallback** for systems that show two letters instead of an emoji flag.
