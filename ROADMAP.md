# Roadmap

Where **NMS // TEXT CODES** is heading. This is a living list, not a promise: priorities can change, and anything done moves to the [changelog](CHANGELOG.md).

---

## 🔧 In progress

- **Nexus Mods page** — publish the guide on Nexus Mods once the project is mature enough; the Nexus badge in the README will then point to the real page.

## 📌 Planned

- **More languages** — German and Italian first. Long-term goal: every language officially supported by No Man's Sky. Each new language follows `docs/prompts/prompt_add_language_NMS_TC.md`.
- **Root page redirect** — make `index.html` (GitHub Pages root) lead straight to the guide.
- **Controller icons (`*_W`)** — check whether the 16 non-functional controller tags can use textures extracted from the game, instead of the old screenshot-based images.
- **Check scripts review** — code review of `docs/scripts/` (translation checks and tests).
- **README anchors** — check that every internal link of the READMEs works on GitHub.

## 💡 Ideas (not scheduled)

- **Right-to-left languages** (Arabic, Hebrew…): the layout would need `dir="rtl"` support.
- **Non-Latin alphabets**: fonts with a wider character coverage, to avoid fallback fonts.
- **Flag fallback** for systems that show two letters instead of an emoji flag.
- Confirm the **12 unconfirmed icon textures** and the exact color of `TRANS_ANM` in-game.
